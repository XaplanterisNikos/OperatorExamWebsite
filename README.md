# Operator Exam Quiz — Website

This repository contains the promotional website for **Operator Exam Quiz**, an Android application designed to help candidates prepare for the theoretical examinations for heavy machinery operators.

## Website

The website is publicly hosted on **Firebase Hosting**:

https://operator-exam-quiz.web.app/

It provides information about the application, its features, the final exam simulation, screenshots, the target audience, and the creator.

The website also includes links to the Android application on Google Play and to the project's public repositories.

## Android Application

**Operator Exam Quiz** is a free, ad-free Android application containing:

- 448 questions
- 15 syllabus chapters
- Final exam simulation with 80 questions
- 90-minute exam timer
- 75% passing threshold
- Support for single and multiple correct answers
- Exam progress and state persistence
- Local attempt history
- Offline operation

Google Play:

https://play.google.com/store/apps/details?id=com.foxnks.xeiristisexamquiz

## Technologies

The website is a static web application built with:

- HTML5
- CSS3
- Firebase Hosting
- Google Search Console
- XML Sitemap
- `robots.txt`

The website does not use a backend API or database.

## Project Structure

The main website files are located in the `public/` directory:

- `index.html` — main website content and structure
- `style.css` — website styling and responsive layout
- `robots.txt` — crawling instructions for search engines
- `sitemap.xml` — sitemap containing the public website URL
- `images/` — application icon, banner and screenshots
